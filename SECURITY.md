# Security Policy

## Supported Versions

The following versions of Code.HP currently receive security updates.

| Version | Supported |
| ------- | :-------: |
| Latest release | ✅ |
| Older releases | ❌ |

Only the latest stable release is supported. Please update to the newest version before reporting a security issue.

---

## Reporting a Vulnerability

If you discover a security vulnerability in Code.HP, please do **not** open a public GitHub issue.

Instead, report it privately by:

- Opening a GitHub Security Advisory (preferred), if enabled.
- Contacting the maintainer directly through GitHub.

Please include:

- A description of the vulnerability.
- Steps to reproduce the issue.
- The affected version of Code.HP.
- Any proof of concept or screenshots, if applicable.
- Your operating system.

---

## Response Process

After receiving a report, I will:

1. Confirm that the report has been received.
2. Investigate the issue.
3. Develop and test a fix if the vulnerability is confirmed.
4. Release a patched version as soon as reasonably possible.
5. Credit the reporter (if they wish) in the release notes.

---

## Scope

Examples of security issues include:

- Remote code execution (RCE)
- Arbitrary file access
- Privilege escalation
- Authentication or authorization bypasses
- Sensitive information disclosure
- Dependency vulnerabilities with a real security impact

The following generally do **not** qualify as security vulnerabilities:

- Feature requests
- UI bugs
- Performance issues
- Crashes that cannot be exploited
- Cosmetic issues

---

Thank you for helping keep Code.HP secure.
